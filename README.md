# Pythagorean Theorem Calculator

A simple C++ program that calculates the hypotenuse of a right-angled triangle using the Pythagorean theorem.

## Formula

\[
c = \sqrt{a^2 + b^2}
\]

- `a` — first side
- `b` — second side
- `c` — hypotenuse (the longest side)

## Technologies

- C++
- `<iostream>` — input and output
- `<cmath>` — mathematical functions

## How to Run

1. Clone this repository.
2. Compile `main.cpp` using a C++ compiler.
3. Run the compiled program.
4. Enter the lengths of sides A and B to calculate the hypotenuse.

## Example

```text
Simple Pythagorean Theorem Calculator
Enter side A of the triangle: 3
Enter side B of the triangle: 4
The hypotenuse (C) is: 5
```
